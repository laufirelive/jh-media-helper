# 音视频混合 MKV 单字幕合并设计

## 背景

当前“音视频混合”功能支持在生成 MKV 时封装主视频、副视频、最终音轨和原始音轨。已有逻辑会保留输入视频自身的字幕流，但没有提供选择外挂字幕文件的入口。

本次增强只解决一个明确场景：用户在封装 MKV 时，可额外选择一个 `.srt` 或 `.ass` 字幕文件，并把它合并进生成的 MKV。

## 目标

1. 在“封装为 MKV”场景下支持选择一个外挂字幕文件。
2. 支持 `.srt` 和 `.ass` 两种字幕格式。
3. 主视频输出和所有副视频 part 输出都合并同一个外挂字幕文件。
4. 保留现有内嵌字幕流，不做字幕烧录。
5. 保持现有音视频混合面板，不新增独立功能页。

## 非目标

1. 不支持多个外挂字幕文件。
2. 不支持字幕语言、标题、默认字幕轨等高级元数据配置。
3. 不做字幕时间轴校验或自动平移。
4. 不把字幕烧录进视频画面。
5. 不在非 MKV 输出中处理字幕。

## 配置设计

扩展 `CombatAudioConfig`：

```python
subtitle_path: str | None = None
```

序列化规则：

- `to_dict()` 写入 `subtitle_path`。
- `from_dict()` 对旧任务配置兼容，缺失时默认为 `None`。
- `__post_init__()` 不需要把空字符串保留下来；空值统一视为 `None`。

任务入队后，字幕路径作为配置快照保存。后续用户修改界面选择，不影响已经入队的任务。

## UI 设计

在“音视频混合”面板右上“输出设置”分组中增加字幕选择能力：

- 位置：`封装为 MKV` 下方、`输出目录` 上方或附近。
- 控件：复用现有 `FileSelector`，标签为 `字幕文件:`。
- 文件过滤：`字幕文件 (*.srt *.ass);;所有文件 (*)`。
- 支持清空选择。如果 `FileSelector` 没有内置清空能力，则新增一个小的“清空”按钮或使用空路径设置。

启用规则：

- 只有主输入是视频且勾选 `封装为 MKV` 时启用。
- 纯音频输入、未选择有效输入、或未勾选 `封装为 MKV` 时禁用。
- 禁用时保留界面路径显示，但构建配置时忽略，不参与校验，不报错。

## 处理流程

1. 用户选择主视频、音频目录、输出目录，并勾选 `封装为 MKV`。
2. 用户可选一个 `.srt` 或 `.ass` 字幕文件。
3. 音频处理流程保持不变：提取、调整时长、混音或仅对齐。
4. 封装 MKV 时构造视频列表：`[主视频] + secondary_video_paths`。
5. 对每个视频执行一次封装：
   - 当前视频的视频流进入输出。
   - 最终音轨按背景音乐顺序进入输出。
   - 当前视频原始音轨按现有规则追加。
   - 当前视频已有字幕流按现有规则保留。
   - 如果配置了 `subtitle_path`，同一个外挂字幕文件追加到每个输出 MKV。

## 封装命令设计

### mkvmerge 后端

`build_mkvmerge_mux_command()` 增加可选参数：

```python
subtitle_path: str | None = None
```

命令构建规则：

- 视频输入段继续保留视频和已有字幕，禁用音频、章节和标签。
- 生成音频输入段继续禁用视频和字幕。
- 原视频音频输入段继续禁用视频和字幕。
- 如果 `subtitle_path` 存在，在末尾追加一个字幕输入段：
  - 禁用视频和音频。
  - 禁用章节、全局标签、轨道标签。
  - 不设为默认字幕轨。

### FFmpeg fallback

`build_mux_command()` 增加可选参数：

```python
subtitle_path: str | None = None
```

命令构建规则：

- `-i video_path` 后继续追加所有最终音频输入。
- 如果 `subtitle_path` 存在，再追加一个字幕输入。
- 映射顺序：
  - `0:v`
  - `0:s?`
  - 所有最终音频输入
  - 原视频音频 `0:a`，如果当前视频有音轨
  - 外挂字幕输入的字幕流
- 编码：
  - 继续使用 `-c copy`。
  - `.srt` 和 `.ass` 都作为 Matroska 支持的文本字幕流复制进输出。
  - 不额外转码字幕，避免影响已有内嵌字幕的格式和样式。

如果后续发现特定 FFmpeg 版本对裸 `.srt` 输入不能直接 copy，再针对外挂字幕输出流做定向转码；本次默认不引入转码。

## 校验设计

扩展 `combat_audio.validate()`：

- 仅当 `config.boxed` 且输入不是纯音频时校验 `subtitle_path`。
- `subtitle_path` 为空时通过。
- 文件不存在时报错：`字幕文件不存在: <path>`。
- 扩展名不是 `.srt` 或 `.ass` 时报错：`字幕文件格式不支持: <path>`。
- 未封装 MKV 或纯音频输入时忽略 `subtitle_path`。

副视频校验逻辑保持不变。

## 错误处理

- 入队前发现字幕路径不存在或格式不支持，直接提示用户并阻止入队。
- 任务执行时封装失败，沿用现有 `MKV 封装失败 part N/M: filename` 错误摘要，并附带后端 stderr 尾部。
- 未选择字幕文件时完全保持现有行为。
- 未封装 MKV 时字幕路径不影响任务。

## 测试策略

### 单元测试

- `CombatAudioConfig`：
  - 默认 `subtitle_path is None`。
  - `to_dict()` / `from_dict()` round-trip 保留字幕路径。
  - 旧配置缺失 `subtitle_path` 时兼容。
- `combat_audio.validate()`：
  - 封装 MKV 时接受存在的 `.srt`。
  - 封装 MKV 时接受存在的 `.ass`。
  - 封装 MKV 时拒绝缺失字幕文件。
  - 封装 MKV 时拒绝非 `.srt/.ass`。
  - 非封装输出时忽略无效字幕路径。
- `build_mux_command()`：
  - 有字幕时追加字幕输入。
  - 有字幕时映射外挂字幕流。
  - 无字幕时命令保持现有结构。
- `build_mkvmerge_mux_command()`：
  - 有字幕时追加字幕输入段。
  - 字幕输入段禁用视频、音频、章节和标签。
  - 无字幕时命令保持现有结构。

### Worker 测试

- `FFmpegWorker` 在 MKV 封装阶段把 `config.subtitle_path` 传给 FFmpeg 后端命令构建器。
- `FFmpegWorker` 在 MKV 封装阶段把 `config.subtitle_path` 传给 mkvmerge 后端命令构建器。
- 多 part 输出时每个 part 都收到同一个字幕路径。

### GUI 测试

- 勾选 `封装为 MKV` 且输入是视频时字幕选择器启用。
- 未勾选 `封装为 MKV` 时字幕选择器禁用，`build_config()` 输出 `subtitle_path is None`。
- 纯音频输入时字幕选择器禁用，`build_config()` 输出 `subtitle_path is None`。
- 视频封装场景中选择 `.srt` 或 `.ass` 后，`build_config()` 输出对应路径。

## 兼容性

旧队列任务和旧配置文件缺少 `subtitle_path` 时继续正常运行。未使用字幕文件时，生成命令应尽量保持现有行为不变，避免影响已有 MKV 封装结果。
